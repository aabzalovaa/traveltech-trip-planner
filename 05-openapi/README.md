# OpenAPI-спецификация

В данной спецификации приведены только ключевые эндпоинты по трём разным сервисам. Она не является полным описанием API и не покрывает все возможные сценарии, методы и служебные операции.

Спецификация предназначена для демонстрации основных контрактов взаимодействия между сервисами и ключевых операций, достаточных для понимания архитектуры и логики работы системы.

## Важное допущение

В реальном проекте для каждого из трёх сервисов была бы подготовлена отдельная OpenAPI-спецификация

Это позволило бы:
- разделить зоны ответственности сервисов;
- независимо версионировать контракты;
- упростить сопровождение и генерацию клиентов;
- публиковать документацию по каждому сервису отдельно.

В рамках текущей спецификации все ключевые эндпоинты трех сервисов собраны в одном файле для наглядности.

# Кейс - TravelTech: сервис планирования путешествий.

## Контекст
TravelTech-сервис позволяет пользователю спланировать поездку в едином интерфейсе: бронировать авиабилеты, забронировать отель, трансфер и активности. Все элементы путешествия синхронизируются между собой, а система предоставляет персонализированные рекомендации на основе интересов пользователя и истории его поездок.

В рамках кейса необходимо спроектировать систему, которая реагирует на задержки и отмены рейсов, уведомляет пользователя, предлагает альтернативные варианты и автоматически обновляет маршрут

## Цель проекта 
Спроектировать отказоустойчивую систему мониторинга рейсов, обеспечивающую своевременное получение информации об изменениях, информирование пользователя и актуализацию плана путешествия с учетом бизнес-ограничений.

## Бизнес-ограничения

- Данные о статусах рейсов поступают с задержкой от внешних поставщиков.
- Пользователь может находиться офлайн.
- При подборе альтернатив необходимо учитывать багаж, визовые ограничения и часовые пояса.
- Паспортные данные запрещено хранить дольше, чем это необходимо для поездки.
